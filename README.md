# Chroma Canvas

Cria um website moderno, premium e altamente profissional para uma empresa especializada em tintas, vernizes e soluções de acabamento para interiores e exteriores.

O website deverá ser desenvolvido em React, com uma arquitetura moderna, componentizada e otimizada para performance, SEO e responsividade.

Inspirar-se na experiência visual, fluidez, organização de conteúdos e sensação premium do website Paulo C. Barbosa, mas sem copiar o design, layouts, identidade visual ou composição exata.

O objetivo é transmitir:

qualidade

confiança

inovação

sofisticação

expertise técnica

proximidade com o cliente

O design deverá ser contemporâneo, elegante e minimalista, utilizando bastante espaço em branco, tipografia forte, imagens impactantes de ambientes pintados e detalhes subtis inspirados no universo da cor, textura e acabamento.

Stack Tecnológica

O projeto deverá ser desenvolvido com:

React

Vite

React Router

Tailwind CSS

Framer Motion para animações suaves

Estrutura componentizada e reutilizável

SEO-friendly

Responsivo em desktop, tablet e mobile
